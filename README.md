Spotify Music Analytics Dashboard

An interactive Power BI dashboard built to analyze Spotify song and artist performance using popularity, chart position, release trends, and album data.

The dashboard helps music analysts, playlist managers, and marketing teams:

- Monitor overall song and artist performance
- Identify top-performing songs and artists
- Analyze popularity trends over time
- Compare explicit and non-explicit songs
- Explore album and single distribution
- Analyze artist consistency and #1 positions
- Drill down into song and artist-level details

🛠️ Tools Used
- Power BI
- DAX
- Power Query
- Microsoft Excel

📊 Dashboard Pages
**Home Page** – Project landing and navigation page  
**Overview** – Overall KPIs, trends, and performance analysis  
**Artists** – Artist popularity, songs, albums, and performance  
**Songs** – Song popularity, album distribution, and detailed analysis
